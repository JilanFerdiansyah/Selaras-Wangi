# Selaras Wangi audit

Date: 2026-10-07. Mode: after, selected by the user. No application changes made.

Scope: the current hero and favorites screen. Results were intentionally removed at the user's request and are excluded from proposed implementation. This is an audit of a prototype, not a release approval.

Direction: retain the original animated orbit, editorial serif typography, restrained palette, and enlarged selected perfume. The user wants small changes and a more distinct identity. Cosmos was an explicit reference, so its influence is not itself an R-30 violation.

Audit reading: perfume comparison for people choosing Indonesian perfumes, with airy editorial styling. Inferred target dials: ENERGY 2 / RHYTHM 2 / MOTION 3. These describe the existing direction, not a new brand brief.

## Numbered findings

### 1. HIGH: enlarge small touch targets (R-03)

Reason: several controls fall below the skill's 44 x 44px minimum.

Measured clear-search button: 23.44 x 37px. Favorite removal chips: 39px high. Change-perfume button: 32px high. Suggestion rows are 70px high and already meet the height requirement.

Proposal: expand invisible hit areas or padding to at least 44px without making the controls visually heavy.

### 2. HIGH: darken search labels and metadata (R-25)

Reason: normal-sized search text fails the skill's 4.5:1 contrast threshold.

Computed using the skill's bundled contrast checker against #fffdf8:

| Text | Color | Contrast |
|---|---|---|
| Price/concentration, 11px | #81877e | 3.62:1 |
| Brand, 11px | #71806f | 4.12:1 |
| Placeholder, 17px on mobile | #7e827b | 3.85:1 |

The dropdown surface is almost opaque cream; these are representative surface calculations, not a claim that every animated background frame was measured. Muted body text #657064 on white passes at 5.18:1.

Proposal: darken these text tokens. Also verify the input boundary and focus indicator against adjacent colors before shipping; pale boundaries should not be the only cue to an input.

### 3. HIGH: provide an identifiable image fallback (R-27)

Reason: failed product images can leave blank circles or broken thumbnails without explaining the state.

Source evidence: productImage hides the image on error. Favorite and suggestion images have no equivalent error fallback. The text labels remain, but the scene loses its primary content. Failure behavior was inspected in source, not induced through network interception.

Proposal: show the brand initials and an explicit image-unavailable label when an image fails. Keep brand and full perfume name readable. Loading treatment should apply to asynchronously loaded images; the local catalog does not need an artificial spinner.

### 4. HIGH under the skill: replace authored em-dash separators (R-02)

Reason: the skill bans the em dash in agent-authored text, and the app uses it between brand and perfume name and in the page title.

Proposal: use a middle dot in assembled labels, retain real catalog product names verbatim, and use a colon in the page title. This is a small compliance cleanup rather than a major design improvement.

### 5. MEDIUM: retire decorative background motion on the favorites screen (R-19)

Reason: the large decorative orbit keeps running alongside the small orbit of actual selected perfumes, dividing attention between two visual systems.

The background already slows after selection, but bottles remain visible across the second screen. The same transition can make the product's identity more specific: browsing possibilities becomes assembling a personal reference set.

Proposal: preserve the user's preferred original hero orbit. On selection, let decorative bottles recede and settle; let the actual target and favorites take over. Maintain the existing reduced-motion path. This honors the explicitly requested orbit rather than treating motion itself as forbidden.

### 6. LOW: make the selected bottle the primary focal point (R-20)

Reason: on the second screen, the headline still has more visual weight than the product the user asked to emphasize.

Mobile target container is 124px, but the actual bottle occupies less of that area because the image contains whitespace. The circular backing is more prominent than some product silhouettes, while the brand/name is a small 12px line.

Proposal: improve image framing using existing assets, soften the circular backing, and reduce the second-screen headline slightly. Give the brand and full perfume name a clear caption with a functional 'Considering' label. Keep the hero headline unchanged. A larger circle alone will not solve the hierarchy.

### 7. LOW: preserve favorites when changing the target (R-20, C-4)

Reason: an action labeled 'Change the perfume I’m considering' also erases the user's favorites, making the effect broader than its wording.

Reproduced: selected HMNS Addict, added HMNS Ambar Janma, clicked the change-perfume control, and returned to the hero. Source confirms favorites = [] in that action.

Proposal: preserve the reference perfumes while choosing a new target. If the new target is already a favorite, remove only that duplicate. Treat a full restart as a separate action only if needed.

### 8. MEDIUM: remove the external-link arrow from search options (R-08)

Reason: every suggestion ends with an up-right arrow, but clicking selects the perfume in the current app rather than opening an external destination.

Proposal: remove it, or use a selection affordance only if it helps explain the actual action. Let the product image and name carry the row. There is no need to add a new icon system.

## What to retain

- The hero question is direct and fits the task. There is no generic marketing paragraph, fake social proof, or template feature grid.
- Serif typography adds a fragrance-editorial character while sans-serif controls stay readable.
- The original orbit is an explicit user preference. The white central mask protects text, peripheral bottles suggest browsing, and selection can turn that motif into meaningful product behavior.
- Cream input surfaces and muted green accents fit the restrained direction. Improve contrast rather than replacing the palette.
- The favorites scene uses real catalog images and connects selection to the comparison concept.

- Reduced-motion support and catalog-failure message were inspected in source, not simulated in this audit.
- A real mobile keyboard, 200% text resizing, full screen-reader behavior, and blocked-image runtime behavior remain unverified.
- The original user tab's perfume and favorites were preserved; testing used a separate temporary tab. Temporary viewport override was reset.

## Delivery Gate evaluation

- Hard Gate: FAIL for the current app: findings 1-4. Existing prototype is not approved for release.

- Craftsmanship and Quality Locks: FAIL for current interaction resilience and hierarchy: findings 6-7. Search, selection, removal, clear, back, and Escape have actual behaviors; no dead result button remains.
